First launch downloads the AI model once (about 4.7 GB). After that, everything runs 100% offline on this computer — nothing you type ever leaves it.

Settings

7B is the fast everyday pick for a 16 GB laptop. 14B is smarter but noticeably slower, and can't use the largest context on 16 GB RAM.
Larger context = longer memory per chat, but more RAM and slower replies. Changing model or context restarts the engine (and downloads the model first if it isn't here yet).
